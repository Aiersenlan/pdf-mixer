# PDF 合併與頁面編輯器

一個完全跑在本機的 PDF 頁面編輯工具，操作方式參考 smallpdf 的 organize-merge 介面：
把多個 PDF／圖片丟進來，用縮圖拖曳排序、旋轉、複製、刪除、插入空白頁，最後輸出成一份新的 PDF。

**所有處理都在瀏覽器記憶體裡完成，檔案不會離開你的電腦**，也不需要網路連線。

---

## 快速開始

### 線上使用（免安裝）

<https://aiersenlan.github.io/pdf-mixer/>

點開就能用，不用裝 Python、不用跑任何腳本、不需要系統權限。
程式碼跟本機版完全一樣，**所有處理依然只發生在你瀏覽器的記憶體裡**，
檔案不會被上傳到任何地方。

### 本機執行

需求：任一現代瀏覽器；有 Python 3 更好，沒有也可以。

```bash
python serve.py
```

Windows 也可以直接雙擊 `start.bat`：偵測到有 Python 就用 `serve.py`，
沒有就自動改用內建的 `serve.ps1`（純 PowerShell 寫的靜態伺服器，
Windows 10/11 內建就能跑，不用另外安裝）。瀏覽器會自動開啟 <http://localhost:9321>。

第一次想試玩的話，先產生範例檔：

```bash
python tools/make_samples.py
```

然後在空白畫面按「載入範例檔案」，會載入 A/B/C/D 四份共 11 頁、顏色分明的測試 PDF。

> 不能用 `file://` 直接開 `index.html`。瀏覽器的安全限制會擋掉 ES module 與 pdf.js 的
> worker，程式偵測到之後會顯示提示。線上版跑在 `https://` 之下，沒有這個限制。

## 功能

**加入檔案**
- 支援 PDF、JPG、PNG、WebP、GIF、BMP（圖片會自動轉成 PNG 再嵌入）
- 拖放到視窗任何位置、按「新增」、點末端的虛線卡片，或點頁與頁之間的「＋」插入到指定位置

**收合成一疊**
- 載入檔案後預設是收合的：同一份文件的**連續頁面**收成一疊，顯示檔名與頁數，最多疊五層
- 點一下（或雙擊）那一疊就展開；展開後第一頁的工具列會多一個收合鈕
- 工具列的「全部展開 / 全部收合」一次切換所有文件
- 分組看的是「連續」而不是「同檔名」，所以 `A1 B1 A2 A3 B2 B3 B4`
  會收成 `A1` `B1` `A2–A3` `B2–B4` 四疊
- 整疊可以直接拖曳、旋轉、刪除、選取，動作會套用到裡面所有頁面

**頁面操作**（滑鼠移到縮圖上方會出現工具列）
- 🔍 放大檢視（或直接在卡片上點兩下）　🔄 向右旋轉 90°　⧉ 複製這一頁　🗑 刪除這一頁
- 拖曳縮圖調整順序；先勾選多頁再拖曳可以整組搬移
- 點縮圖切換選取，`Shift` + 點擊可以連續選一段
- 「＋」→「添加空白頁」會沿用鄰頁的紙張尺寸

**分割成多個檔案**
- 「＋」→「新增分割符號」會插入一個剪刀標記，按下「完成」時從那裡切成另一個檔案
- 「新增」→「在文件之間加入分割符號」一次在所有來源文件的交界插入標記
- 「新增」→「在文件之間加入空白頁」則是插入空白頁而不是切檔
- 有分割符號時，匯出的檔名會自動變成 `名稱_1.pdf`、`名稱_2.pdf`…，
  匯出對話框會先列出將產生哪些檔案；瀏覽器可能會詢問是否允許一次下載多個檔案
- 依檔名排序會清掉分割符號（重排後原本的位置已經沒有意義），排序完會提示清掉了幾個

**整體操作**
- `檔案` / `頁面` 兩種檢視：檔案檢視可以整份調順序、整份旋轉、整份移除
- 格狀 / 清單兩種排版，右上角滑桿調整縮圖大小
- 排序：檔案名稱 A→Z、Z→A、反轉順序、還原成加入時的順序
- 完整的復原／重做（最多 60 步）。展開／收合屬於檢視設定，不佔用復原步驟

**鍵盤快速鍵**

| 按鍵 | 動作 |
| --- | --- |
| `Ctrl` + `Z` | 復原 |
| `Ctrl` + `Y` / `Ctrl` + `Shift` + `Z` | 重做 |
| `Ctrl` + `A` | 全選 |
| `Delete` / `Backspace` | 刪除所選頁面 |
| `R` / `Shift` + `R` | 向右／向左旋轉 90° |
| `←` `→` | 預覽時切換上一頁／下一頁 |
| `Esc` | 關閉視窗、取消選取 |

### 資料模型

`store.pages` 是唯一的順序來源，每一筆代表輸出 PDF 裡的一頁：

```js
{
  id: 'p12',
  kind: 'pdf' | 'image' | 'blank' | 'split',
  fileId: 'f3',      // 對應 store.files 裡的來源檔案
  srcIndex: 2,       // 在來源檔案裡的第幾頁（0 起算）
  rotation: 90,      // 0 / 90 / 180 / 270
  selected: false,
  width, height,     // 未旋轉時的紙張尺寸（pt）
  seq: 7,            // 加入的先後，供「還原原始順序」使用
}
```

`kind: 'split'` 是分割符號，本身不產生頁面，只是把後面的內容切到下一個輸出檔案。
它一樣放在 `pages` 陣列裡，所以拖曳、刪除、復原全部沿用既有機制，
匯出時再用 `splitSegments()` 把陣列切成數段。

收合是由 `pageGroups()` 即時算出來的：掃過 `pages`，把**連續同 `fileId`** 的頁面
歸成一組，分割符號與空白頁各自成組。展開狀態存在 `store.groupMode`（布林）
加上 `store.expanded`（一組群組首頁的 id），屬於檢視狀態，不進復原歷史。

每張卡片都帶 `data-index` / `data-end` 兩個陣列索引，
收合後一張卡片代表好幾頁時，拖曳的插入點才算得準。

複製一頁只是多一筆指向同一個 `fileId` / `srcIndex` 的記錄，不會複製位元組。
`store.files` 只存原始位元組與外觀（顏色、檔名），刪光某檔案的頁面後仍會保留，
這樣復原才拿得回來。

### 匯出的旋轉處理

旋轉一律寫進 PDF 的 `/Rotate`，MediaBox 保持原本尺寸，由閱讀器負責換邊顯示：

```js
copied.setRotation(degrees((copied.getRotation().angle + page.rotation) % 360));
```

這樣不會重繪頁面內容，文字與向量圖形都完整保留，檔案也不會變大。

## 已知限制

- **不支援 Word / Excel / PowerPoint**。這些格式要正確轉檔需要完整的 Office 排版引擎，
  純前端做不到。如果需要，得另外接一個本機的 LibreOffice `soffice --convert-to pdf` 後端。
- **有密碼的 PDF 無法開啟**，載入時會顯示錯誤訊息。
- 沒有「輸出後保留表單欄位互動性」的處理；`pdf-lib` 的 `copyPages` 會保留頁面內容與註解，
  但跨文件的 AcroForm 欄位可能失去部分行為。
- 極大的檔案（數百 MB、上千頁）會吃掉不少記憶體，因為整份檔案都留在瀏覽器裡。
